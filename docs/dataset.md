## 지금 있는 것

[somae/so101-cube-regions](https://huggingface.co/datasets/somae/so101-cube-regions)

| 항목 | 값 |
|---|---|
| 에피소드 | 100 |
| 프레임 | 42,202 (30 fps, 에피소드당 약 14초) |
| 카메라 | 위, 손목 각 640×360, AV1 영상 |
| 상태, 동작 | 관절 6개 (어깨 회전, 어깨, 팔꿈치, 손목 굽힘, 손목 회전, 그리퍼) |
| 지시문 | 6가지 문장 × 칸 3개 (숫자, 색, 숫자와 색 각 2가지) |
| 시작과 끝 | HOME 자세 |
| 큐브 | 3 cm, 빨간 면이 위 |
| 놓는 자리 | 어깨에서 205~260 mm, 칸 경계에서 약 37 mm 안쪽 (중앙값) |
| 집기 | 손목 카메라로 맞춘 뒤 한 번에 집음. 놓친 장면 없음 |

## 녹화 규칙

- 녹화는 HOME에서 시작해 HOME에서 끝냄
- 놓은 뒤 위 카메라로 확인해 목표 칸이 아니면 저장하지 않음
- 지시문은 `merge_relabel.py`가 에피소드마다 6가지 중 하나를 붙임
